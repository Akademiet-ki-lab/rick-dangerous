# Tempeltårnet

Et lite plattformspill i nettleseren: klatre fire etasjer i et tempel, unngå vakter, piler og pigger, og hent gullidolet.

**Spill her:** https://akademiet-ki-lab.github.io/rick-dangerous/

## Kontroller

- Tastatur: ← → går, ↑ ↓ klatrer, mellomrom hopper, X skyter, C legger dynamitt, P pauser.
- Mobil: spilles liggende med styrekryss og knapper på skjermen.

Alt ligger i `index.html`, uten byggesteg eller avhengigheter.
